Connect once

This page runs downloads on GitHub Actions. It needs a GitHub token, which stays in this browser and is sent only to github.com.

  1. Open github.com token settings.
  2. Under Repository access choose Only select repositories, then coursera-to-drive.
  3. Under Permissions set Actions to Read and write.
  4. Generate the token, copy it, and paste it below.
